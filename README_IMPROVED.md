# CARD ROGUELIKE v29.1

## v29.1 - COMMON TREE BALANCE PASS

v29で追加した全体スキルツリーの「取得順と強さ」を調整しました。

### 1. ショップ強化を序盤から撤去

取引ルート序盤の「上質な仕入れ」を廃止し、
**「品揃え拡張」**へ変更しました。

- 取得前：ショップのカード商品 3枚
- 取得後：ショップのカード商品 4枚

序盤から強化済みカードが大量に並ぶことはなくなります。

### 2. 取引ルート最深部を強化

弱かった合流後の「地下商圏」を、
**「特選仕入れ」**へ変更しました。

ショップを訪れるたび、
強化可能なカード商品のうち **1枚だけ** が必ず強化済みになります。

「全商品強化」にはせず、最深部らしい強さと選択の余地を両立しています。

### 3. 強化ルート最深部も少し強化

「熟練の手入れ」は、
通常報酬の強化済みカード出現率を **15% → 30%** に上昇。
さらにショップでも15%で強化済みカードが混ざるようになります。

取引ルートの「確定1枚」と組み合わせた場合も、
ショップ全体が必ず強化済みになる仕様ではありません。

### 4. 既存セーブへの配慮

ノードIDと必要SPは維持しているため、
v29のセーブデータをそのまま利用できます。

カード / レリック解放だけではなく、
キャラクター固有の戦い方そのものを変える最深部ノードを追加しました。

戦士：

機工士：
- 各ターン最初のエナジー獲得を増幅
- エナジーペナルティをブロックへ変換
- 次ターンのエナジーペナルティを1軽減

墓守：
- 捨て札10枚以上で次ターンエナジー+1

- 各ターン2枚目の回収で1ドロー

- イベント「眠れる鍛冶場」

- 通常カード報酬が15%で強化済みになる
- 上位ノードでその確率を25%へ
- 通常戦カード報酬候補 +1
- ショップカードが15%で強化済みになる
- ショップの商品カード枠 3 → 4

### 4. セーブ互換

v28以前のキャラクター別SP / 解放済みノードはそのまま読み込みます。
新しい共通ツリーは0SPから開始します。

# CARD ROGUELIKE v28

## v28 - CARD UPGRADE SYSTEM

### 1. 休憩所に「カード強化」を追加

休憩所で、これまでの「休む」に加えて「カードを強化」を選べるようになりました。

- 休む：最大HPの30%相当を回復
- カードを強化：デッキから1枚を選んで強化

1回の休憩所につき、どちらか片方だけ選択します。

### 2. 強化カード

強化されたカードは名前に `+` が付きます。

例：

- スラッシュ → スラッシュ+
- ガード → ガード+
- バッシュ → バッシュ+

強化内容はカードごとの主効果に合わせて変化し、ダメージ・ブロック・回復・闘志・エナジー・捨て札参照などを強化します。

### 3. 強化カードの表示

- 戦闘中は強化カードに `UP` バッジを表示
- 枠を少し強調して通常カードと区別
- カード説明に今回の強化内容を表示

### 4. 深淵の核との相互作用

「深淵の核」はこれまで通り休憩所での回復を禁止しますが、カード強化は利用できます。

### 5. 既存セーブとの互換性

未強化カードのIDは変更していません。既存デッキはそのまま利用でき、強化後のみ内部的に強化版IDへ置き換わります。
